# Refine design: "Lamplight"

This folder holds the design work for the Refine (InWords) web app. It is research and design only, and no app code is changed.

- `research/`: the product and UI analysis of the PRD and repo, a PRD robustness review, and the inspiration gap fill.
- `direction/`: the Lamplight design direction (tokens, type, motion and screen direction) and the moodboard (`moodboard.html` and `moodboard.png`).
- `screens/`: 15 mobile-first PWA screens as an interactive prototype (`prototype.html`; open it in a browser), PNG renders, and `motion.mp4`, a clip of the signature motion moments played at 1.8x.
- `inspiration/`: Pinterest and Dribbble reference screenshots, with source links in the research docs.

The photos are mood placeholders taken from the inspiration pins and are not for production.
